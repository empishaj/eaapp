# Technische Lernroadmap für Enterprise Architecture

Die folgenden Themen sind als Vertiefungsblöcke geplant. Sie ergänzen die vorhandene Projektbibliothek und die 100 technischen Leitsätze.

1. Architekturentscheidungen und ADRs auf Principal-Niveau
2. Distributed Systems: Delivery Semantics, Retry, Backoff, Jitter, Circuit Breaker, Bulkhead, DLQ, Replay, Saga, Outbox
3. Datenkonsistenz: CAP, Quorum, Leader/Follower, Eventual Consistency, Conflict Resolution
4. API Architecture: REST, gRPC, GraphQL, Webhooks, Versionierung, Error Contracts, Contract Testing
5. Event-Driven Architecture: Events, Kafka, Partitionen, Consumer Groups, Schema Evolution, Replay
6. Domain-Driven Design für EAs: Bounded Contexts, Context Maps, Anti-Corruption Layer
7. Microservices kritisch bewerten: modularer Monolith, Distributed Monolith, Service Boundaries
8. Platform Engineering: Internal Developer Platform, Golden Paths, Self-Service, Policy-as-Code
9. Cloud Architecture: Public/Private/Hybrid/Sovereign Cloud, Landing Zones, Exit-Strategie
10. IAM: OAuth/OIDC, SAML, RBAC/ABAC, PAM, Machine Identities
11. Security Architecture: Zero Trust, Threat Modeling, STRIDE, SBOM, Supply Chain Security
12. Observability/SRE: Metrics, Logs, Traces, SLI/SLO, Error Budgets, Business Observability
13. Resilienz/BCM: HA, DR, Backup, Restore, RTO/RPO, Notbetrieb, Nachpflege
14. Data Governance: Ownership, Stewardship, MDM, Metadata, Lineage, Data Contracts, Data Mesh
15. AI Architecture: LLM, RAG, Embeddings, Guardrails, Evaluation, Human-in-the-loop
16. DMS/eAkte: Akte, Vorgang, Dokument, Metadaten, Scan, Zustellung, Archivierung, Löschung
17. Architektur in Vergabe und EVB-IT
18. Technische Dienstleistersteuerung und Architekturabnahme
19. EA vs Solution vs Software vs Platform Architect
20. Architekturmetriken und KPIs
21. EA-Reifegradmodell für Bundesbehörden
22. Architektur-Anti-Patterns
23. Architecture Review Masterclass mit Reviewfragen
24. EA in Krisen, Incidents und Eskalationen
